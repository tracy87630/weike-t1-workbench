# T1 首捐轉定期工作台

給勸募專員用的工作台：匯入捐款人名單後，自動找出「首捐後 60 天內的單筆捐款人」（T1），依首捐天數分到三封信，並套用每季替換的信件素材。

## 轉換流程

| 時間點 | 信件 | 目標 |
|---|---|---|
| Day 0 | 首捐感謝信 | 固定內容：感謝與微客介紹 |
| Day 30 | 成果故事（上集） | 邀請轉為定期定額 |
| Day 50 | 成果故事（下集）・已轉定期 | 鼓勵分享、邀請親友 |
| Day 50 | 成果故事（下集）・未轉定期 | 再次邀請定期定額 |

## 怎麼用

1. 用瀏覽器打開 `index.html`。
2. 拖入捐款系統匯出的 .xlsx（需包含「①捐款人名單」與「②一年內捐款紀錄」兩個分頁）。可先用 `data/微客_示範資料_v1.xlsx` 試用。
3. 點時間軸上的卡片切換收件群，點收件人預覽套好資料的信，可複製單封或匯出整群 CSV。
4. 到「信件素材管理」替換本季的成果故事與文案；用「匯出素材檔」把整套素材分享給同事。

## 檔案

- `index.html`：本機版。名單只在瀏覽器裡計算，素材與「已寄」標記存在這台電腦的瀏覽器。
- `artifact/T1首捐轉定期工作台.html`：claude.ai Artifact 版，信件素材存在團隊共用的資料庫，只能在 claude.ai 裡使用。
- `data/微客_示範資料_v1.xlsx`：AI Impact Day 示範資料，內容全部虛構。

## T1 判斷規則

- 一年內捐款紀錄中的第一筆是單筆，且距基準日 60 天內（可調整）。
- 名單上有比首捐更早開始的定期方案者視為老捐款人，排除。
- 首捐後出現定期定額扣款，或有首捐後開始且進行中的方案，視為「已轉定期」。
- 沒有 email 或從來不開信的人，標示改用簡訊／紙本。

注意：捐款紀錄只有一年，更早以前捐過的人可能被誤認為新朋友。
